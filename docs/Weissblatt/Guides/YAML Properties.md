As you can see above, [Obsidian-flavored Markdown](https://help.obsidian.md/Editing+and+formatting/Obsidian+Flavored+Markdown) features support for YAML front matter to add metadata. Some properties such as `tags` and `aliases` are additionally recognized by obsidian for additional functionality, such as named links and tag-based grouping.

# Tags and Aliases

Tag should be written in lower-case and singular for consistency, unless the tag reflects a name or acronym. In that case, you should opt to use the official spelling.
